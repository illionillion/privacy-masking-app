date: 2026-05-17

---

編集画面の **マスキング操作 UI** を整理しました。

矩形追加まわりを **マスキング種別セレクタ** に統一し、ぼかし・モザイクなどの種別を選びやすくしています。OCR で検出した領域も同じ仕組みで管理し、選択後に種別を変更できます。

**顔スタンプ用のカスタムピッカー** も追加しました。ツールバーはコンパクトなまま、一覧では絵文字とラベルでスタンプを選べます。細かい矩形調整と合わせて、マスクの追加・変更がしやすくなっています。

変更の詳細は [Pull Request #62](https://github.com/illionillion/privacy-masking-app/pull/62) および [Pull Request #64](https://github.com/illionillion/privacy-masking-app/pull/64) を参照してください。
