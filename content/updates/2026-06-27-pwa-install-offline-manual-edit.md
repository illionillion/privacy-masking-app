title: PWA 対応とオフライン手動編集モード
date: 2026-06-27
summary: ホーム画面への追加やアプリとしてのインストールに対応しました。オフライン時は手動マスキングのみ利用できます（自動検出はオフラインでは無効）。
---

伏せ太郎を **PWA（Progressive Web App）** として使えるようにしました。Chrome や Safari から「アプリをインストール」「ホーム画面に追加」ができ、インストール後は [/app](/app) をアプリのように起動できます。

あわせて **オフライン手動編集モード** を追加しました。ネットワークが使えないときは、画面上部に案内バナーが表示され、画像の追加と手動マスキング（矩形・スタンプ・ぼかしなど）は引き続き利用できます。顔検出・OCR などの **自動検出はオフラインでは利用できません**。スタンプ画像は一度オンラインで読み込んだ後、オフラインでも利用しやすいようキャッシュしています。

画像データはこれまでどおり **ブラウザ内だけで処理** し、Service Worker にユーザーのアップロード画像は保存しません。

変更の詳細は [Pull Request #94](https://github.com/illionillion/privacy-masking-app/pull/94)（PWA 導入）および [Pull Request #95](https://github.com/illionillion/privacy-masking-app/pull/95)（オフライン手動編集）を参照してください。
