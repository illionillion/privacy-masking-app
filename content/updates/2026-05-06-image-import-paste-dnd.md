summary: Ctrl+V / Cmd+V でスクリーンショットを直接貼り付け、別タブや外部アプリから画像をドラッグ＆ドロップして取り込めるようになりました。
---

画像の取り込み方法を **2 つ追加** しました。

**クリップボードからの貼り付け（Ctrl+V / Cmd+V）** では、スクリーンショットを撮ったあとファイル保存せず、そのままマスキング処理を開始できます。**別タブ・外部アプリからのドラッグ＆ドロップ** では、ブラウザ上の画像や他アプリから画像をドロップして取り込めます。

いずれもブラウザ内だけで画像を扱い、サーバーへデータを送ることはありません。スクリーンショット中心のワークフローが短くなり、日常使いしやすくなっています。

変更の詳細は [Pull Request #29](https://github.com/illionillion/privacy-masking-app/pull/29) および [Pull Request #30](https://github.com/illionillion/privacy-masking-app/pull/30) を参照してください。
