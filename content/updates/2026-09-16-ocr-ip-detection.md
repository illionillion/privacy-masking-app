---
title: OCR で IP アドレスも検出できるように
date: 2026-09-16
summary: 文字検出（OCR）の対象に IPv4 / IPv6 を追加し、ネットワーク設定やログのスクショに写った IP も自動でマスクしやすくしました。
---

OCR の個人情報検出に **IP アドレス**（IPv4 / IPv6）を追加しました。ポート付きの IPv4（例: `10.0.0.1:8080`）や、圧縮表記の IPv6 も検出対象です。

ネットワーク設定画面やサーバーログのスクショを SNS・チケットに貼る前に、IP の写り込みを減らせます。URL に含まれる IP は従来どおり URL 全体としてマスクします。

OCR は端末性能や文字サイズに依存するため、100% の検出は保証できません。見落としがあれば編集画面から手動でマスク領域を追加してください。

変更の詳細は [Pull Request #138](https://github.com/illionillion/privacy-masking-app/pull/138) を参照してください。
