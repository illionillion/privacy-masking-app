---
title: スマホのギャラリーでプレビューと編集を切り替え
date: 2026-05-12
summary: スマートフォンではギャラリーをプレビュー表示と編集画面に切り替える方式に変更。スクロールしやすく、誤操作も減らしました。
---

**スマートフォン（768px 未満）** のギャラリー表示を見直しました。従来は編集用 Canvas が常時表示され、縦スクロールが阻害されたり、スクロール操作でマスクが意図せず動くことがありました。

SP では **プレビュー（画像のみ）** と **編集（ツールバー＋ Canvas）** を切り替える方式に変更しています。一覧をスクロールして確認し、編集したい画像だけ編集モードに入れられます。PC では従来どおり常時編集 UI を表示します。

変更の詳細は [Pull Request #51](https://github.com/illionillion/privacy-masking-app/pull/51) を参照してください。
