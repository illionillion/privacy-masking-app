date: 2026-05-21
summary: ギャラリー内の編集 UI をモーダルに集約。PC とスマートフォンで同じ編集フローになり、プレビューと編集の切り分けも明確になりました。
---

ギャラリー内の編集 UI を **モーダルに集約** し、PC とスマートフォンで **同じ操作フロー** に統一しました。

ギャラリー本体はマスク済みプレビューのみを表示し、編集時だけ Canvas を 1 枚マウントします。**完了** で保存、**キャンセル**（オーバーレイクリック含む）では未保存の変更を破棄する前に確認ダイアログを表示します。

一覧で全体を確認し、必要な画像だけ編集に入る——という流れが分かりやすくなり、その後のズーム・パンやスマホ向け編集改善の土台にもなっています。

変更の詳細は [Pull Request #67](https://github.com/illionillion/privacy-masking-app/pull/67) を参照してください。
