画像の読み込ませ方

伏せ太郎に画像を追加して、マスキング編集を始める手順を説明します。

目次
  1. ドロップゾーンに画像をドラッグ&ドロップ

ドロップゾーンに画像をドラッグ&ドロップ

ドロップゾーンに画像をドラッグ&ドロップするか、ドロップゾーンをクリックすると画像選択と読み込みができます！ 読み込まれたら自動でマスキング処理が走るので完了するまでお待ちください

スマホの場合はこちら

スマホではドロップゾーンをタップして、写真ライブラリやファイルから画像を選びます。
