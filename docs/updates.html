更新情報

伏せ太郎（Fusely）の機能追加・改善をお知らせします。ユーザー向けの変更のみ掲載しています。

  • 2026年6月10日

    OCR の電話番号検出を改善

    Tesseract のページ分割モードを調整し、電話番号の取りこぼしを減らしました。郵便番号との誤判定も見直しています。

  • 2026年6月9日

    顔検出・OCR の個別スキップ設定を追加

    顔だけ・文字だけなど、自動検出する種類を選べる設定を追加しました。設定はブラウザ内に保存され、次回以降も維持されます。

  • 2026年6月1日

    トップページを LP 化しツールを /app に分離

    サービス紹介をトップ（/）に、マスキングツール本体を /app に分けました。FAQ や更新情報など読むページも追加しやすい構成です。

  • 2026年5月25日

    スマホ向け編集 UI の改善

    編集モーダルに操作ヒントを追加し、初回読み込みやスタンプ選択の使い勝手をスマートフォン向けに調整しました。

  • 2026年5月24日

    編集画面のズーム・パン操作に対応

    編集モーダルでマウスホイール・ドラッグによる拡大縮小と移動（パン）に対応。細かいマスク調整がしやすくなりました。

  • 2026年5月21日

    編集 UI をモーダルに集約し PC/SP の操作を統一

    ギャラリー内の編集 UI をモーダルに集約。PC とスマートフォンで同じ編集フローになり、プレビューと編集の切り分けも明確になりました。

  • 2026年5月17日

    エディタのマスキング種別選択とスタンプピッカーを改善

    矩形追加 UI をマスキング種別セレクタに統一し、顔スタンプ用のカスタムピッカーを追加。OCR 検出結果の種別変更にも対応しました。

  • 2026年5月12日

    スマホのギャラリーでプレビューと編集を切り替え

    スマートフォンではギャラリーをプレビュー表示と編集画面に切り替える方式に変更。スクロールしやすく、誤操作も減らしました。

  • 2026年5月10日

    共通フッターとプライバシーポリシー・利用規約ページを追加

    サイト全体に共通フッターを設け、プライバシーポリシー（/privacy）と利用規約（/terms）を公開しました。GitHub への問い合わせ導線もまとめています。

  • 2026年5月6日

    クリップボード貼り付けと外部ドラッグ＆ドロップに対応

    Ctrl+V / Cmd+V でスクリーンショットを直接貼り付け、別タブや外部アプリから画像をドラッグ＆ドロップして取り込めるようになりました。

  • 2026年4月24日

    画像アップロードの操作性改善とモバイル対応

    ドラッグ＆ドロップやファイル選択の使い勝手を見直し、スマートフォンでも画像を取り込みやすくしました。
